<a name="boss-design"></a>

## ⚔️ Creating Boss Fights

* 🧠 **AI & Behaviors:** Creating state machines and behavior trees that drive boss attack choices and patterns.
* 🔄 **Phases & Escalation:** Structuring dynamic fights with multiple phases, dynamic triggers, and changing mechanics.
* 🎯 **Telegraphs & Timings:** Crafting clear attack telegraphs so players can learn, dodge, and counter.
* 💥 **Combat Feel:** Balancing animation timing, hitboxes, and audio/visual cues for impactful hits.
